# 🏀 シュート記録トラッカー

バスケのシュートを **コート上の地点ごとに記録**して、成功率を見返せる PWA（インストール可能・オフライン動作）。

## 特長
- コートをタップ → その地点で「何本中何本決めたか」を入力（キーボード / ＋−）
- 1セットの本数を設定（各地点◯/20 など）
- 成功率で色分け（緑70%↑ / 黄50〜69% / 赤49%↓）
- マイエリア（練習メニュー付き）… 選ぶだけでスポットを自動配置
- デフォルトメニュー3種（3Pの5ヶ所 / ミドルの5ヶ所 / 全10ヶ所）
- 打つ人の名前ごとの成績、シュートチャート、ゾーン別成功率、履歴
- データは端末内（localStorage）に保存。書き出し / 読み込みも可能

## 使い方
`index.html` をブラウザで開くだけ。スマホでは「ホーム画面に追加」でアプリのように使えます。

## 技術
- 単一の `index.html`（依存ライブラリなし）＋ `manifest.json` ＋ `sw.js`
- データはブラウザの localStorage に保存（サーバー不要）

## デプロイ（GitHub Pages）
1. このフォルダを GitHub リポジトリに push
2. Settings → Pages → Branch を `main` / `/ (root)` に設定
3. 発行された `https://<ユーザー名>.github.io/<リポジトリ名>/` を開いてホーム画面に追加
